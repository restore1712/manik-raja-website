PANDUAN AKTIVASI RESET PASSWORD ADMIN (UNTUK SERVER ONLINE)

Alur reset email sudah tersedia, tetapi sengaja tidak aktif sebelum konfigurasi server siap.

1. Jalankan database.sql pada database marga_manik. File ini menambahkan kolom email/verifikasi/versi sesi serta tabel token reset dan verifikasi.
2. Pasang website di domain HTTPS.
3. Atur environment variable pada server web:
   APP_BASE_URL=https://domain-website-anda
   MAIL_FROM=admin@domain-website-anda
   APP_KEY=<rahasia acak sekurangnya 32 karakter>
4. Konfigurasikan mail transport server agar fungsi PHP mail() dapat mengirim melalui penyedia SMTP yang dipakai hosting. Jangan simpan password SMTP di repository.
5. Login sebagai admin, buka “Keamanan akun admin”, masukkan email pemulihan dan password saat ini, lalu klik “Simpan dan kirim verifikasi”. Reset email baru aktif setelah link verifikasi dibuka.
6. Uji permintaan reset, masa berlaku 30 menit, penggunaan token satu kali, pembatasan lima permintaan per IP per jam, serta invalidasi sesi setelah password diganti.

Catatan:
- APP_BASE_URL harus berupa URL HTTPS tetap dan tanpa garis miring di akhir.
- APP_KEY harus unik, acak, dan tidak disimpan di repository. Gunakan pembangkit rahasia yang aman pada server.
- Jika hosting tidak mengatur mail() ke SMTP terautentikasi, pasang dan konfigurasi mail transport atau integrasikan pustaka SMTP yang dikelola Composer sebelum mengaktifkan fitur.
- Di XAMPP lokal, email reset tidak dikirim sampai seluruh konfigurasi tersebut tersedia.
